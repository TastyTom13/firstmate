=== 3. All four keys in the environment; only the invoked lane's key reaches pi ===
$ GROQ_API_KEY=fake-groq CEREBRAS_API_KEY=fake-cere CLOUDFLARE_API_KEY=fake-cf OPENROUTER_API_KEY=fake-or bin/fm-free-lane-run.sh groq -p 'hello'

[fake pi] lane keys visible in my environment:
FM_FREE_LANE_ACTIVE=1
GROQ_API_KEY=fake-groq
exit=0

$ ...same environment... bin/fm-free-lane-run.sh openrouter -p 'hello'

[fake pi] lane keys visible in my environment:

=== 4. A lane session cannot start another lane (exit 4) ===
$ FM_FREE_LANE_ACTIVE=1 bin/fm-free-lane-run.sh cerebras
error: a free-tier lane may not start another free-tier lane
hint: FM_FREE_LANE_ACTIVE marks this process tree as already inside a lane
exit=4

=== 5. Cloudflare with an unfilled account id in the pi models file (exit 3) ===
$ CLOUDFLARE_API_KEY=fake-cf bin/fm-free-lane-run.sh cloudflare
error: the 'cloudflare' provider in $TMP/agent/models.json still has an unfilled account segment
hint: pi does not expand variables in baseUrl; type your own Cloudflare account id into that file
exit=3

=== 6. One-time launcher install (the single av bless the owner runs) ===
$ bin/fm-free-lane-run.sh --install-launcher
installed: $TMP/home/config/free-lane-launcher
next (owner, once): av bless '$TMP/home/config/free-lane-launcher'

$ cat $FM_HOME/config/free-lane-launcher
#!/private$TMP/fakebin/av inject +GROQ_API_KEY +CEREBRAS_API_KEY +CLOUDFLARE_API_KEY +OPENROUTER_API_KEY -- /bin/bash
# Generated by bin/fm-free-lane-run.sh --install-launcher. Home-local, gitignored.
# Its shebang carries this machine's av path and the four free-tier lane keys.
# One-time owner step: av bless '$TMP/home/config/free-lane-launcher'
exec '$FM_ROOT'/bin/fm-free-lane-run.sh "$@"
